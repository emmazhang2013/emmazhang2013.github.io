# Posting Workflow

This file is the source of truth for publishing new posts to Emma's Little House.

## Goal

When a new draft arrives, turn it into a publishable Jekyll post, add one illustration unless the user opts out, preview the page locally, then commit, push, and verify the live site.

## Repo And Branch

- Repository: `/Users/opc0nt7/codex_ws/emmazhang2013.github.io-src`
- Publish branch: `MyBlog`
- Site URL: `https://emmazhang2013.github.io/`

## Expected Input

The user can provide as little as a title plus body. These fields are optional unless noted:

- `title`
- `body` or full draft text
- `date`
- `categories`
- `tags`
- `slug`
- `image_prompt`
- `image_style`
- `image_opt_out`

If some fields are missing, choose sensible defaults from the article content.

## Default Editorial Rules

- Preserve the author's meaning and voice.
- Lightly polish grammar, punctuation, and paragraphing so the post reads cleanly.
- Do not rewrite into a different tone unless the user asks.
- Keep markdown simple and readable.
- Use one illustration near the top of the post unless the user says not to.

## Post File Rules

- Create posts in `_posts/`.
- Filename format: `YYYY-MM-DD-slug.md`
- Use `layout: single`
- Use `+0800` timezone in front matter.
- Store categories and tags as YAML lists.
- Insert the illustration immediately after the front matter.

Standard image line:

```md
![插图](/assets/images/misc_imgs/<image-file>.png "Generated by OpenAI")
```

## Image Rules

- Save generated images under `assets/images/misc_imgs/`.
- Default image filename: `<slug>.png`
- Prefer one landscape illustration that matches the article theme.
- If the title contains non-Latin characters and the slug is unclear, set `--slug` manually.
- When generating the image in Codex, use the `imagegen` skill.

## Recommended Flow

1. Read the draft and infer any missing metadata.
2. Scaffold the post with `scripts/new_post.sh`.
3. Replace the placeholder body with the final markdown.
4. Generate one illustration and save it to `assets/images/misc_imgs/`.
5. Check the post in local preview.
6. Commit with a clear message.
7. Push to `origin MyBlog`.
8. Verify the live page after GitHub Pages redeploys.

## Scaffold Command

Example:

```bash
cd /Users/opc0nt7/codex_ws/emmazhang2013.github.io-src
scripts/new_post.sh \
  --title "A Great Website" \
  --date 2026-04-11 \
  --category "FCE" \
  --tag "Review"
```

For Chinese titles or custom filenames, pass `--slug` explicitly:

```bash
scripts/new_post.sh \
  --title "《你好灯塔》读后感" \
  --slug "nihaodengda" \
  --category "Reading Notes" \
  --tag "Book Review"
```
